# Séance 3 TICE 6e — Architecte des dossiers

Mini-site autonome pour une séance de 55 minutes. Aucune installation ni connexion Internet n’est nécessaire.

## Utilisation en classe

1. Ouvrir `index.html` dans un navigateur récent.
2. Cliquer sur **Commencer la mission**.
3. Faire les sept défis dans l’ordre. Le score, la progression et les aides sont intégrés.

Le site peut être copié sur le réseau du collège ou sur une clé USB. Les fichiers `index.html`, `style.css` et `script.js` doivent rester ensemble dans le même dossier.

## Publication avec GitHub Pages

1. Créer un nouveau dépôt GitHub public, par exemple `Architecte-des-dossiers`.
2. Ajouter à la racine du dépôt : `index.html`, `style.css`, `script.js` et ce fichier `README.md`.
3. Dans le dépôt, ouvrir **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main`, le dossier `/ (root)`, puis cliquer sur **Save**.
6. Attendre une à deux minutes : l’adresse du site s’affiche dans la section Pages.

## Personnalisation rapide

- Les couleurs principales sont regroupées au début de `style.css`.
- Les consignes, réponses et aides sont dans `script.js`.
- Le pied de page et les textes d’accueil sont dans `index.html`.

Dans le défi 4, un nom est accepté s’il contient au moins deux mots utiles. Les espaces, tirets et traits de soulignement sont autorisés. Pour les fichiers, l’extension demandée doit être conservée.

Tous les noms d’élèves présents dans les exercices sont fictifs.
